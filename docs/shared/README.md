# Shared Documents

`docs/shared/` stores facts that affect more than one lane.

Use this area for:

- Cross-lane contracts.
- Shared types or data models.
- Integration issues.
- Shared risks that cannot be owned by only one lane.

Do not use this directory as a replacement for `docs/project/**`, lane boards, or implementation notes. Shared documents are controlled documents; worker sessions may propose changes, but should not silently change contracts or shared constraints.
