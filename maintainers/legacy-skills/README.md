# Legacy Skills Source

This directory keeps historical D5/D6 skill sources for maintainer reference.
They are legacy source, not installable DIAYN V1 skills, and not public DIAYN V1 skills.

Do not copy these folders into `skills/`, `plugins/docs-is-all-you-need/skills/`,
or a packaged `.claude/skills` / `.codex/skills` install unless a future
maintainer task explicitly redesigns and revalidates them.

The DIAYN V1 public workflow surface is still exactly the 12 `diayn-*` workflow
skills documented in `skills/README.md`.
