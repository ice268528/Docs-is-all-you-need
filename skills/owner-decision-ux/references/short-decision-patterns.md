# Short Decision Patterns

Use these when the Owner can make a small decision quickly.

## Popup Preferred

If the current tool supports a decision popup, prefer it for 2-3 concrete options.

## Markdown Fallback

```text
Owner Decision Needed

Question: <one sentence>

Recommended: A - <short option>

Options:
1. A - <short, concrete choice>
2. B - <short, concrete choice>
3. C - <short, concrete choice>

Reply with A, B, or C.
```

## Rules

- Keep every option short and selectable.
- Put the recommended option first when appropriate.
- Avoid long background paragraphs.
- Link to details only when needed.
- Record the final decision in a durable Markdown record or formal project doc.
