Should the next stage reuse clean lane worktrees or create new ones?

The Owner needs a simple choice before the Controller prepares the next stage baseline.

Recommended

A because reuse keeps the workflow simpler when worktrees are clean and aligned.

What Changes

The Controller either keeps the current lane directories or plans new ones.

Main Risk

Reusing a dirty or misaligned worktree could carry stale state into the next stage.

Options

A Recommended

Reuse clean aligned worktrees

Owner impact: Fewer directories and a faster next-stage start.

Delivery impact: Controller verifies cleanliness and baseline alignment first.

Risk: Must stop if any worktree is dirty or misaligned.

Future impact: Keeps a stable lane directory layout.

B

Create new lane worktrees

Owner impact: More directories but stronger isolation.

Delivery impact: Controller plans new paths and branch names.

Risk: More cleanup and branch tracking later.

Future impact: Keeps the old stage directories available for investigation.

ChoiceBest forTradeoffNext step
A Normal next-stage continuation Requires a clean-state check Run Controller baseline refresh
B Dirty or uncertain lane state More workspace overhead Run /diayn-worktrees with new paths
