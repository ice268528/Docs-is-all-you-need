# DIAYN Session Entry Checklist

Use this checklist at the start of every `/diayn-*` work turn, especially after a new session or cleared context.

| Check | Pass? | Evidence |
| --- | --- | --- |
| Requested command matches expected role | `<yes/no>` | `<command>` |
| Current path matches manifest or local identity | `<yes/no/Unknown>` | `<path>` |
| Lane matches command for worker/reviewer workflows | `<yes/no/not_applicable>` | `<lane>` |
| Required lane board and handoff are visible | `<yes/no/not_applicable>` | `<paths>` |
| Worker has stopped before same-lane review | `<yes/no/not_applicable>` | `<report/status>` |
| Current action stays inside allowed write paths | `<yes/no>` | `<paths>` |

Stop on wrong role, wrong worktree, missing handoff, premature review, or unknown write boundary.
